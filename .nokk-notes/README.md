# Снятые ленты

Здесь лежит то, что дорого снимать заново: каждый прогон по заставе тратит
доверие к адресу, а часть этих лент снята с настоящего Chrome.

| файл | что это |
|---|---|
| `our_strings.json`, `chr_strings.json` | поля тела первого POST по порядку — наши и хромовские |
| `our_strings2.json` | то же после починки размеров по проводу |
| `our_walks.json`, `our_walk.json`, `chr_walk.json` | что обход графа спрашивает у интерфейсов и какие числа получает |
| `chr_protos.json`, `our_protos.json` | описания всех членов всех прототипов (950 интерфейсов) |
| `chr_worker.json`, `our_worker6.json` | область воркера: собственные имена |
| `chr_win.json`, `our_win3.json` | собственные имена окна, в порядке заведения |
| `window_order.json` | хвост порядка имён окна — из него собран `WINDOW_ORDER` в `crates/stealth` |

Как снимать заново — в памяти, запись «Where we stopped». Каталог в `.gitignore`
не значится намеренно: ленты маленькие и полезны рядом с кодом.
